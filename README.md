# Yuhan Zhu (Zuzu) — Personal Portfolio

The source for [inovamenz-code.github.io](https://inovamenz-code.github.io/): a small static personal portfolio for projects, learning, and creative work.

## Pages

- `index.html` — personal homepage and selected work
- `projects.html` — combined project and coursework archive
- `about.html` — background, working approach, and current toolkit
- `now.html` — concise work-in-progress record
- `contact.html` — contact details and professional links

## Local preview

This site has no build step. Open `index.html` in a browser, or serve this folder with any static-file server.

## Publishing principles

Public project material is intentionally smaller than each working project. Do not add course briefs, solution archives, build caches, research data, model weights, secrets, or third-party assets whose distribution rights are not confirmed.
