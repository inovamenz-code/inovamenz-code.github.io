MSc Dissertation · Unity · Python

Adaptive Game Music Tool自适应游戏音乐工具

My MSc dissertation project connects Unity gameplay to local Python music-generation services. Location, combat and health determine the prompt; the generated MIDI or WAV plays in Unity alongside scene ambience.我的硕士毕设把 Unity 游戏与本地 Python 音乐生成服务连接起来，根据地点、战斗和生命值组织提示词，再将生成的 MIDI 或 WAV 放回游戏中播放，同时保留场景环境音。
